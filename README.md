# Run Simple Python Project Manually

This example demonstrates how to manually run a simple Python script, simulating the process of getting a GitHub project up and running on your local machine. It shows a basic project structure with a main entry point, configuration variables, and how to pass arguments. The script prints project information to the console, illustrating a successful execution.

## Language

`python`

## How to Run

1. Save the code as `main.py`.
2. Open a terminal or command prompt and navigate to the directory where you saved `main.py`.
3. Run the script using `python main.py` or `python main.py 1.2.3` to provide a custom version.
